## About

I'm an independent developer focused on building polished software products
with modern technologies, AI-assisted engineering, and thoughtful UI/UX.

我相信，好的软件不只是功能的集合，也应该拥有清晰的设计语言、
流畅的交互体验，以及值得长期维护的工程架构。

- Building modern desktop applications and web products.
- Exploring AI Agents, automation, and AI-powered workflows.
- Designing minimal interfaces with a focus on detail.
- Turning ideas into practical, open-source products.
